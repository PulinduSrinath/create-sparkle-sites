# DevCraft

## Web & App Development Agency

DevCraft builds high-performance websites and apps using Next.js, React, and modern technologies.

## Project Structure

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Development

To start the development server:

```sh
# Install dependencies
npm install

# Run the development server
npm run dev
```

## Deployment

Build the project for production:

```sh
npm run build
```
